# REUSE compliance with ReuseMe

ReuseMe (CI: `dev-build-deploy/reuse-me`) fails a pull request when a file has no copyright or no licence, or when `LICENSES/` lacks a licence a file uses (PR001). The `reuse-me` plugin hook keeps Claude from causing that: it adds the header to every new file it writes that can hold one, and makes sure the rest is covered by `.reuse/dep5`.

## Headers first, annotations only where a header cannot go

Prefer an in-file header over an annotation, always. A header travels with the file: when it is copied into another project, pasted into a gist or leaks, the copyright and licence are still in it, and anyone can trace where it came from. An entry in `.reuse/dep5` or `REUSE.toml` stays behind in the repository and says nothing once the file is elsewhere.

- **Header** (source, scripts, shaders, Lua, Go, C, shell, YAML, TOML, CSS, Markdown and HTML via `<!-- -->`...): a comment at the top with the two tags (`SPDX-FileCopyrightText`, `SPDX-License-Identifier`) in the file's own comment syntax. After a shebang, an XML declaration, an HTML doctype or Markdown front matter; never before them. Every new file with a comment syntax gets one, **even when `.reuse/dep5` or `REUSE.toml` already covers its path**.
- **Annotation** (pictures, models, fonts, audio, JSON, binaries: files that cannot hold a comment): no header. Covered by a `.reuse/dep5` stanza (`Files:`, `Copyright:`, `License:`) or a `REUSE.toml` `[[annotations]]` entry. A `<file>.license` sidecar only where the repository asks for sidecars.

What the hook does with a new file:

| The new file | Covered by dep5 / REUSE.toml | Not covered |
| --- | --- | --- |
| has a comment syntax | gets the header (and a warning, see below) | gets the header |
| has none | written as it is | denied, naming the dep5 stanza to add |

- **Double coverage**: `.reuse/dep5` and a header add up, so a file in both shows two licence entries in the SBOM. When the hook adds a header to a file a dep5 stanza also covers, it warns: narrow or drop that stanza's `Files:` glob so the header is the one source. `REUSE.toml` with the default `precedence = "closest"` yields to the header, so it does not warn; `aggregate` and `override` do.
- **Uncovered comment-less file**: the deny message holds the exact stanza (path, copyright, licence from `.reuse-me.json`). Add it to `.reuse/dep5` in the same change and write again. If the repository generates its dep5 from a script, add the path to that script's source instead. The hook appends the stanza itself only when `.reuse-me.json` says `"dep5": "append"`.

## Where the values come from

`.reuse-me.json` in the repository root (first matching rule wins):

```json
{
  "rules": [
    { "paths": ["engine/**"], "holder": "Kevin de Jong <monkaii@hotmail.com>", "year": 2024, "license": "MPL-2.0" },
    { "paths": ["games/**"],  "holder": "Kevin de Jong <monkaii@hotmail.com>", "license": "LicenseRef-Proprietary" }
  ],
  "defaults": { "holder": "Kevin de Jong <monkaii@hotmail.com>" },
  "exclude": ["vendor/**"]
}
```

- `paths`: globs relative to the root (`**` crosses folders, `*` does not; no slash matches at any depth).
- `holder`: a string or list; the year is prefixed unless the holder starts with one. `year` defaults to the current year.
- `defaults`: used when no rule matches. Without a default licence, the only file in `LICENSES/` is used; with none or several the hook denies: `no licence rule for <path>: add one to .reuse-me.json`. Do not guess: add the rule (ask the user which licence when unclear) and write again.
- `dep5`: `"deny"` (the default: a new comment-less file no annotation covers is refused with the stanza to add) or `"append"` (the hook appends that stanza to `.reuse/dep5`). Keep `"deny"` when dep5 is generated by a script, since a hand edit would be overwritten.
- `sidecars`: `true` makes the hook write a `<file>.license` sidecar for such a file instead. Off unless the repository wants sidecars.
- `exclude`: paths the hook never touches. A repository without `.reuse-me.json`, `REUSE.toml`, `.reuse/dep5` or `LICENSES/` is not enforced at all.

## Adding a new licence

1. Put the full text in `LICENSES/<SPDX-ID>.txt` (SPDX ids from spdx.org/licenses; a custom one must be `LicenseRef-<letters, digits, . or ->` with its own text file, FL003).
2. Add or change the rule in `.reuse-me.json`.
3. Remove licence files nothing uses any more (PR002).

## Third-party files

Keep their own header and licence intact (an existing header is never replaced). Vendored files without headers that you cannot edit go into `.reuse/dep5` or `REUSE.toml` with the upstream copyright and licence, and their licence text into `LICENSES/`. Never relabel third-party code with the repository's licence.

## Existing files and shell writes

The hook only rewrites a `Write` that creates a file. Editing an existing file leaves its header alone. A file created through `Bash` (`cat >`, `tee`) is not seen: add the header yourself, in the same form the hook would.

## Check before pushing

`npx reuse-me` / the `reuse-me` CLI (see docs/cli.md) validates locally what CI will check.
